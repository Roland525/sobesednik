# Собеседник 1.1.5

- Реплики, которые не подходят для постоянной памяти, отбрасываются до обращения к разговорной модели. Фоновые обрывки больше не тратят время модели только ради пустого результата отбора.
- История диалога передаётся перед изменяемыми цитатами общей беседы. Изменение этих цитат больше не меняет префикс уже обработанной истории.
- Генерация текста, синтез голоса и воспроизведение работают отдельными ограниченными очередями. Модель продолжает отдавать текст, пока CPU озвучивает предыдущее предложение. Остановка и ошибки закрывают поток генерации.
- В памяти по умолчанию показаны пригодные сведения. Старые автоматические обрывки доступны через переключатель «Показать старые автозаписи, которые бот не использует»; они не удаляются и не используются в ответах. Поиск и удаление работают с выбранной видимой записью.

Выбранная модель, качество распознавания, голос и его темп не меняются ради ускорения. Это уменьшение лишней работы и пауз конвейера, а не обещание одинаковой секундной задержки на любом компьютере. Краткий контекст по-прежнему очищается при перезапуске; постоянная память сохраняется.
