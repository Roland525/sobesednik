# Собеседник 1.1.3

Исправлены ошибки, найденные при проверке установки, управления и постоянной памяти.

- Повторная установка восстанавливает неполную распаковку Vosk и Ollama. Компонент сначала целиком проверяется в отдельной папке; повреждённый архив не публикуется как готовый.
- При переключении папки данных очищаются сведения о прежнем Discord-боте, черновик токена, контекст, диагностика и рекомендации моделей. Переключение ждёт завершения фоновых операций.
- Сохранение настроек сохраняет допустимые прежние значения темпа, краткости и режима общения, включая точность нетронутых значений громкости и темпа.
- Обычное сохранение больше не пересчитывает потоки CPU и размещение модели на GPU, если ползунок ресурсов не меняли.
- Скрытая поиском запись памяти не может случайно стать целью удаления.
- Фразы от первого лица не приписываются другому упомянутому участнику. Явное и автоматическое обновление работы/учёбы заменяет текущий факт с сохранением истории.
- Автоматическая проверка исправлений для дообучения больше не принимает ответ только за высокий процент общих слов: изменение ключевого факта или числа отклоняется. Свободные перефразировки требуют отдельной проверки и автоматически не засчитываются.

Изменения не требуют сброса моделей, токена, персоны и памяти. Просмотр Discord Go Live не добавлен.
