# Приложение «Собеседник» для Windows

## Цель
Один установочный EXE из GitHub Releases. Пользователю не нужны терминал,
заранее установленный Python или ручное редактирование JSON. После установки
ярлык открывает панель, из которой настраиваются и запускаются локальные модели
и Discord-бот. Прежний запуск исходников сохраняется.

## Выбранный подход
Пользователь выбрал обычную установку с ярлыком. Предлагаемая реализация:
PySide6/Qt Widgets, упакованное приложение и установщик Inno Setup без прав
администратора. Переносная папка была альтернативой; браузерная панель добавила
бы отдельный сервер и не соответствовала бы запросу на обычное окно приложения.

Программа устанавливается в LocalAppData/Programs/Sobesednik. Рабочие данные,
модели, Python и зависимости — в LocalAppData/Sobesednik. Обновление программы
не удаляет токен, модели, память или персону. Существующая рабочая установка
разработчика при сборке и испытании не изменяется.

## Окно
Тёмный графитовый фон, светлая типографика, мятный основной акцент, умеренные
скругления, ясные подписи. Минимум 1040×720, изменение размера, прокрутка.
Никаких фиктивных показателей: неизвестные значения показываются прочерком.

- **Обзор:** состояние установки и бота, Запустить/Остановить/Перезапустить,
  текущий канал, CPU/RAM/GPU/видеопамять, последняя измеренная задержка.
- **Discord:** скрытый ввод токена, Проверить, Developer Portal, инструкция,
  пригласительная ссылка, список серверов и голосовых каналов, Войти/Выйти.
  Показываются только реально доступные боту каналы.
- **Голос и ответы:** имя обращения, скорость и громкость, голос M1–M5,
  краткость, редкие вмешательства или только обращения, размер истории.
  Изменения валидируются. Требующий перезапуска параметр не выдаётся за
  применённый к уже работающей модели.
- **Персона:** редактор PERSONA.md с сохранением и резервной копией.
  Контекст текущего разговора показывается отдельно; его можно сбросить.
- **Память:** поиск, сервер, участник, сведения, автор и дата. Отдельно
  показываются учебные примеры. Удалить запись, забыть участника или очистить
  память можно после явного подтверждения с указанием объёма удаления.
  Удаление примеров не объявляется стиранием уже обученных весов.
- **Журнал:** ограниченный хвост событий, понятные ошибки и копирование
  диагностического текста с удалённым токеном.

## Первая настройка
1. Выбор папки данных; проверка Windows x64, диска и ресурсов.
2. Скачивание из закреплённых источников изолированного Python, зависимостей,
   Ollama, STT, wake-word и Supertonic, затем локальной LLM.
3. Прогресс по этапам, журнал, отмена и повтор после ошибки без удаления уже
   скачанных моделей. Установка не требует ввода токена в консоли.
4. Ввод и проверка токена, приглашение бота, выбор сервера и канала.
5. Запуск из этого же окна. Дополнительное LoRA-обучение обозначено как
   экспериментальное и отдельно от немедленно работающей памяти.

Первый релиз сохраняет уже проверенный профиль моделей: NVIDIA с 8 ГБ
видеопамяти и 32 ГБ RAM рекомендуется для отзывчивого разговора. На CPU
запуск допускается с заметным предупреждением о медленной работе; отдельные
облегчённые модели не подменяют проверенную модель автоматически. В мастере
можно выбрать экономное распознавание small вместо large-v3-turbo.

## Границы и устройство
GUI не загружает тяжёлые STT/LLM/TTS в свой процесс. Бот остаётся отдельным
процессом. Команды ограничены фиксированным списком операций; ни Discord,
ни модель не могут передать через панель произвольную команду ОС.
Обмен управлением — локальные файлы запросов/ответов в папке пользователя,
без сервера, открытого в сеть. Токен не попадает в командную строку, журналы
или публичную сборку; хранение нового токена защищается Windows DPAPI.
Долгие операции выполняются вне потока интерфейса. Чужие процессы не
останавливаются. Остановка и перезапуск учитывают голосовой supervisor и
цикл обучения. Изменения памяти синхронизируются с работающим ботом.

## Проверки и поставка
Тесты настройки, валидации, локальных команд, ошибок Discord, SQLite,
завершения процессов, обновления с сохранением данных и безопасной распаковки.
Настоящие Qt-проверки переходов и действий, снимки всех экранов и визуальная
проверка. Сборка установочного EXE, испытание в отдельном чистом профиле,
контроль отсутствия секретов, публикация EXE и SHA-256 в GitHub Releases.

в эту функцию и не рекламируется как доступный.
