# Desktop Application Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Publish a tested Windows installer EXE with local setup and a complete bot dashboard.
**Architecture:** A frozen PySide6 application owns setup and the backend supervisor. An allowlisted backend payload is installed into a per-user data folder; an authenticated local file protocol exposes only fixed bot operations. Models and existing state survive application updates.
**Tech Stack:** Python 3.11, PySide6 Essentials 6.12.0, psutil 7.2.2, PyInstaller 6.22.3, Inno Setup.
**Spec:** docs/superpowers/specs/2026-10-23-desktop-design.md (approved by user).

## Global Constraints
- Windows x64; per-user installation without admin or a preinstalled Python.
- Local STT/LLM/TTS only, no paid API. Preserve legacy source startup.
- Tokens never in arguments, logs, source payload or release assets; DPAPI for new UI credentials.
- No Go Live viewing claim. Experimental training and memory remain distinct.
- Default M3, eight denoising steps, speed 1.06.
- Existing production processes and private working tree are not modified.

## Review Focus
- Interrupted downloads and invalid archives must never produce a ready installation.
- Updates preserve config, persona, databases and models.
- Startup/shutdown and training must not leave duplicate GPU workers.
- Failed Discord credentials/rate limits are human-readable and never leak token text.
- Memory deletion must be scoped, confirmed, and reflected in active context/training.
