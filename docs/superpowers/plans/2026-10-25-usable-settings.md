# Понятные настройки и аккуратная память

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development. Track verification below.

**Goal:** Устранить перечисленные пользователем проблемы, сохранив личные данные и работающие голосовые функции.

**Architecture:** Существующий Qt-интерфейс и тёмная палитра сохраняются. Общие виджеты отвечают за колёсико, уведомления и короткие анимации. Конфигурация получает два реальных режима вычислений вместо процентов. Смысловой отбор памяти усиливается без удаления старых записей и без выдачи краткого контекста за обучение весов.

**Tech Stack:** Python 3.11, PySide6, локальная Ollama, SQLite.

**Spec:** Подробное сообщение пользователя от 25 октября: уведомления, анимации, колёсико, понятные модели/ресурсы/проверка, пресеты характера и качество автоматической памяти. Ранее пользователь поручил самостоятельно выбирать реализацию без остановок на каждом шаге.

## Constraints and design

- Не запускать рабочую модель ради проверки интерфейса; тестировать в отдельных профилях.
- Сохранить токен, выбранную модель, голос, громкость, темп, персону и базы.
- Уведомления закрываются кнопкой и по таймеру; переходное сообщение перезапуска сменяется подтверждением фактической готовности.
- Колёсико прокручивает страницу, а не меняет закрытые combo/spin controls. Клавиатура и выбор из открытого списка остаются доступны.
- Раскрытие блоков и уведомления: 150–200 мс, без задержки действий; учитывать отключение анимации в Windows.
- Модели: понятное назначение + точное имя в деталях, размер и факт установки. Не объявлять модель умнее без измерения.
- Вычисления: auto (Ollama размещает на GPU), cpu (разговорная модель на CPU); старые настройки мигрируют без перезаписи голоса и памяти.
- Проверка модели: до запуска понятное пустое состояние, во время — видимый этап/прогресс/отмена, после — результат. Тест не является рейтингом интеллекта.
- Пресеты: обычный, жёсткий с матом, спокойный объясняющий. Выбор сначала показывает текст, применяется явным сохранением; пользовательская персона не заменяется при открытии.
- Автоматическая память отбирает устойчивые законченные сведения. Обрывки, вопросы, реакции, команды и одноразовые события не сохраняются автоматически. Явные просьбы запомнить по-прежнему работают.
- Обучение весов остаётся отдельной экспериментальной возможностью с честным статусом, без автоматического скачивания десятков ГБ и нагрузки ради этой правки.

## Review focus

- Повторный restart раньше окончания анимации/таймера не скрывает новое важное сообщение.
- Ошибка операции не выдаётся за успешную готовность после появления gateway.
- Custom/learned модель вне каталога не теряется при сохранении.
- Прокрутка страницы над сфокусированным полем не изменяет его значение.
- Обрывки памяти не удаляются из пользовательской базы без явного решения владельца; фильтр влияет на новые автоматические записи.
