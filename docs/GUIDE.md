# Руководство пользователя

Локальный голосовой ИИ для Discord под Windows: слушает обращение, отвечает голосом,
помнит участников и поддерживает короткий разговор. Без платных API и облачных STT/LLM/TTS.
Мат не запикивается; характер настраивается в разделе «Характер».

## Установка одним EXE

**[Скачать Собеседник для Windows](https://github.com/Roland525/sobesednik/releases/download/v1.1.1/Sobesednik-Setup-1.1.1.exe)** · [Все выпуски и SHA-256](https://github.com/Roland525/sobesednik/releases)

1. Скачайте EXE и установите приложение. Права администратора и заранее установленный Python не нужны.
2. Откройте ярлык **«Собеседник»**. На **Главной** раскройте **Установка и обслуживание** и нажмите **Установить компоненты**. При первой настройке этот блок уже открыт.
   Мастер скачает отдельный Python, зависимости, Ollama, распознавание и синтез речи, разговорную модель.
   Нужно минимум 20 ГБ свободного места; первая загрузка занимает несколько гигабайт.
3. Откройте **Подключение**: кнопка ведёт прямо в Developer Portal, рядом есть инструкция.
   Вставьте Bot Token в скрытое поле, нажмите **«Проверить и сохранить»**, затем **«Пригласить бота»**.
4. На **Главной** нажмите **Запустить бота**, выберите сервер сверху, канал под кнопками и нажмите **Присоединиться**.
5. Скажите: **«Собеседник, почему небо голубое?»**

В приложении доступны темп и громкость речи, голос, краткость, режим обращений,
редактор персоны и истории разговора, просмотр памяти с авторством, удаление записей,
учебные примеры, журнал и настоящие показатели CPU/RAM/NVIDIA GPU.
Изменения параметров моделей применяются после перезапуска; новая персона — в следующих вопросах.

Приложение ставится в `%LOCALAPPDATA%\Programs\Sobesednik`, модели и данные —
в `%LOCALAPPDATA%\Sobesednik\engine`. Можно выбрать другую папку в панели.
Новый токен защищается Windows DPAPI для вашей учётной записи. Обновления и удаление
самой программы не удаляют папку моделей, память и настройки.

Если бот уже установлен из исходников, выберите его папку на вкладке «Главная».
Остановите старый процесс, нажмите «Проверить / доустановить», затем запускайте из панели.
`config.json`, `.env`, `PERSONA.md`, модели и базы сохраняются. Токен из прежней
установки можно проверить и защитить кнопкой в разделе Discord.

Сборка не имеет коммерческой цифровой подписи; Windows может показывать неизвестного
издателя. Сверяйте SHA-256 с файлом в том же GitHub Release. Модели работают локально.

## Как получить токен бота

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications),
   нажмите **New Application**, задайте имя «Собеседник».
2. Откройте **Bot → Reset Token**, подтвердите действие и скопируйте новый токен.
   Вставьте его в раздел Discord приложения. Это именно bot token, а не Application ID и не Client Secret.
   Токен в чат, GitHub и ролики не отправляйте.
3. В **Installation** включите **Guild Install**. В настройках установки выберите
   scopes **bot** и **applications.commands**. Нужны права **View Channels, Connect, Speak,
   Send Messages**. **Change Nickname** можно добавить для изменения ника на сервере.
   Права Administrator не нужны.
4. В **Install Link** выберите **Discord Provided Link**, откройте ссылку и добавьте
   бота на свой сервер. Для этого нужны права управления сервером.

Привилегированные Presence, Server Members и Message Content intents для стандартных
slash-команд не нужны. Если включаете старые команды с `!`, потребуется Message Content.

Токен можно настроить позже: скопировать `.env.example` в `.env` и заполнить `DISCORD_TOKEN=`.
После **Reset Token** прежний токен перестаёт работать — сохраните новый в разделе Discord приложения (при запуске из исходников — в `.env`).
Официальные инструкции: [создание приложения](https://github.com/discord/discord-api-docs/blob/main/developers/quick-start/getting-started.mdx),
[получение нового токена](https://support-dev.discord.com/hc/en-us/articles/6470840524311-Why-can-t-I-copy-my-bot-s-token).

## Как с ним говорить

- Имя можно произносить в начале, середине или конце вопроса. «Серёга» сохранён как
  совместимое обращение. Основное имя меняется через `wake_word` в `config.json`.
- После ответа можно продолжить связанную тему без повторного имени. Случайная фраза
  другого разговора не считается продолжением автоматически.
- По умолчанию включён `rare`: очень редкие короткие дополнения после паузы и проверки
  уместности. `/mode strict` оставляет только прямые обращения. Бесконечных монологов в тишине нет.
- **«Собеседник, заткнись»**, «помолчи», «завали ебало» или `/mute` останавливают речь и очередь.
  Следующее нормальное обращение по имени снова разрешает ответ; отдельное «говори» не требуется.
- Обычный ответ короткий. Для длинного объяснения попросите «подробно» или «по шагам».
- «Собеседник, перейди в канал Общий». Или: «Зайди в Общий, скажи: начинаем через минуту, и вернись».
  Название должно соответствовать доступному голосовому каналу. При неоднозначности он уточнит.

Команды: `/join`, `/leave`, `/status`, `/ping`, `/ask`, `/say`, `/reset`, `/mute`, `/unmute`,
`/listenall`, `/listenme`, `/mode`. Управлять голосом могут люди из того же канала либо
управляющий сервером. После кика можно снова вызвать `/join`; переносы между каналами
обрабатываются с восстановлением голосового приёма.

## Память и обучение — разные функции

В разделе **Память** отдельно включаются прослушивание беседы канала, автоматический
отбор сведений, сбор учебных примеров и LoRA-дообучение. Прослушивание не разрешает
отвечать на каждую реплику: правило обращения по имени сохраняется.

Обычные фразы вроде «Я работаю дизайнером», «Мне нравится играть в шахматы» и
«По пятницам мы собираемся играть» сохраняются без команды «запомни».
Явные сведения обрабатываются сразу, более сложные — локальной моделью в паузах.
Сохраняются исходная реплика и её автор; вопросы, секреты, явные шутки и временные
действия отбрасываются. Автоматический отбор может ошибаться: записи можно проверить
и удалить в приложении. Таблица обновляется автоматически.

Недавняя беседа канала помогает понять текущую тему. Подходящие прошлые исправления
и отобранные пары человеческих реплик подставляются как образцы ответа. Это начинает
работать сразу и не меняет веса модели. Временный контекст очищается при перезапуске,
а сведения и учебные примеры хранятся в локальных базах.

Постоянная память работает сразу и переживает перезапуск:

- «Запомни: моя любимая игра — Dota 2».
- «Меня зовут Паша».
- «Запомни: Паша — это ник ExampleUser».
- «Что ты обо мне помнишь?»; «Какая моя любимая игра?».
- «Забудь всё обо мне» удаляет связанные записи и учебные примеры.

Имена привязываются к Discord ID, а чужие утверждения сохраняют автора. Бот не должен
выдавать шутку об участнике за проверенный факт. Память хранится в `data/memory.sqlite3`.

**Настоящее LoRA-дообучение** — отдельная экспериментальная возможность. Для установки
запустите `setup_learning.bat`: нужны CUDA GPU, дополнительная загрузка около 20 ГБ и минимум
55 ГБ свободного места для временного экспорта модели. Голосовое окружение остаётся отдельным.
Установщик включает `learning_capture_enabled` и `learning_auto_enabled`.
Подготовленная база обучения совместима только с Qwen 3 8B и её локально обученными
производными. При выборе другой модели автоматический цикл не меняет её на 8B.

Учебный корпус — `data/learning.sqlite3`. В него попадают человеческие диалоги и явные
исправления: «Правильный ответ: ...» или подтверждение «Это правильный ответ» после ответа бота.
Автоматический отбор пропускает только содержательные пары вопрос/объяснение; короткий шум,
ответные вопросы и личные представления не используются как анонимные цели модели.
Неподтверждённые ответы самого бота не обучают его по кругу.

Обучение запускается только при одном сервере, после 30 минут без людей в подключённом
голосовом канале, с 32 новыми записями, минимум 16 пригодными примерами и перерывом минимум
6 часов между попытками. На это время бот отключается и освобождает GPU. После цикла
он возвращается. Обучение и голос не выполняются одновременно.

Новые веса проходят отдельную проверку loss, ответов и задержки с загруженным Whisper.
Неудачный кандидат отклоняется; снижение loss само по себе не означает, что бот стал умнее.
Проверки снижают риск ухудшения, но не гарантируют истинность каждого ответа.
Удаление примеров не стирает их из ранее обученных весов: такой адаптер нужно построить
заново из очищенного корпуса. Подробности — [LOCAL_LEARNING.md](LOCAL_LEARNING.md).

## Настройки и ограничения

### Диагностика разговора и исправления

В **Журнале** показаны последние 24 распознанные реплики, правило ответа, результат,
измерения и сведения из памяти, фактически переданные модели. Это события программы,
а не скрытые рассуждения модели. При сбросе и удалении памяти участника список очищается.
Диагностика остаётся локальной.

Выберите реплику и нажмите **Не понял вопрос** или **Неверный ответ**.
Исправления сохраняются в локальной `data/learning.sqlite3`, таблица `feedback`.
Исправление вопроса не считается правильным ответом; повторное исправление заменяет
прежнюю цель обучения. Сведения, зависящие от личной памяти, и распознанные личные
вопросы сохраняются как обратная связь, без включения в общие цели весового обучения.
Для этого боту не требуется включённый сбор учебных примеров.

**Проверить исправления** запускается при остановленном боте. Короткий ожидаемый ответ
сравнивается по точному правилу (с нормализацией цифр 0–9 и пунктуации), длинный —
по совпадению слов от 75%, с учётом отрицания. Это ограниченная проверка формулировок,
не универсальная оценка смысла. Локально обученный кандидат должен пройти и эти
проверки перед применением. Удаление памяти участника/сервера удаляет связанные
исправления; очистка учебных примеров также очищает их.

### Автоподбор под компьютер

В **Настройки бота → Модель** доступен подбор для установленных моделей при бюджете 70 и 100.
В отдельном процессе загружается Whisper и голос с соответствующими параметрами CPU.
Четыре синтетические озвученные фразы распознаются, затем ответы каждой модели
проверяются дважды и синтезируются. Время до первого PCM включает измеренное
распознавание и паузу окончания речи; загрузка весов и сеть Discord в него не входят.
Личная персона и разговоры в тест не подставляются. Во время сравнения Whisper
остаётся в памяти, поэтому конкуренция за VRAM учитывается.

Рекомендация требует не менее 7/8 успешных проверок, сначала выбирает точность,
затем задержку. При неудовлетворительных результатах рекомендации нет. Применение
отдельной кнопкой; отмена не меняет настройки и запрашивает выгрузку тестируемой модели.
Синтетический тест не гарантирует такую же задержку в живом канале.

### Продолжение разговора и поручения

Связанные уточнения без повторного имени и перебивание ответа включаются отдельно.
Продолжать тему может текущий собеседник, а обращение к другому участнику не даёт
боту права ответить. Если человек ещё договаривает до начала озвучки, бот ждёт до
1,2 секунды и объединяет подходящее продолжение вопроса. Явное «заткнись» сохраняет
приоритет. Редкие самостоятельные дополнения не становятся чаще.

В **Подключение → Голосовые поручения** отображаются фактические этапы: найден канал,
переход, озвучка, передача и возврат. Прерванная озвучка не считается доставкой,
а неудачный возврат не отображается как полное выполнение. Для одинаковых названий
каналов бот уточняет категорию; похожее название само по себе не запускает переход.

### Остальные параметры

- На странице **Настройки бота → Модель** кнопки сохранения закреплены над прокруткой.
  Установленные модели помечены; повторная загрузка для них отключена.
- **Ресурсы компьютера** управляют CPU-потоками и выгрузкой слоёв модели на GPU.
  На 0 модель использует CPU; на 70–100 разрешены все слои на GPU, если хватает VRAM.
  Это бюджет вычислений, а не фиксированный процент загрузки. У озвучки установлен
  предел 4 потока: лишние потоки могут замедлять Supertonic. Темп речи задаётся отдельно.
- **Проверить выбранную модель** запускает четыре коротких задания, каждое дважды,
  и сохраняет ответы, точность по заданному правилу и время до первого предложения.
  Проверка доступна при остановленном боте и использует только синтетические вопросы.
  Это измерение на вашем ПК, а не универсальный рейтинг интеллекта; распознавание и
  озвучка в него не входят. Размер установленного файла не равен потреблению RAM/VRAM.

- `PERSONA.md` — характер, манера и длина ответа. `config.json` — модели, голос, режим общения.
- Whisper large-v3-turbo, Vosk, Qwen3 8B через Ollama, Supertonic 3 M3: всё локально.
  Выбранный голос: 8 шагов синтеза, скорость 1.06; Piper доступен как запасной движок.
- LLM не получает командную оболочку и произвольный доступ к файлам. Голосовые действия
  ограничены реализованными командами Discord; история разговора не становится кодом.
- Интернет нужен Discord и установщику. Чтение официальных патчноутов Dota 2 отдельно
  включается через `dota_patch_source_enabled`; текст разговора в Valve не отправляется.
- **Просмотр Discord Go Live этим ботом не реализован.** Он не видит экран и не должен
  придумывать его содержимое. Скринкаст, второй аккаунт и облачная модель в проект не встроены.
- Голосовой приём использует экспериментальный `discord-ext-voice-recv`; совместимость
  с изменениями Discord требует обновлений. Закреплённые версии и DAVE-проверки находятся в коде.

Секреты, настройки, базы, разговоры, модели и журналы не входят в публичный репозиторий.
Не публикуйте свою рабочую папку целиком. Для разработчиков: `python -m unittest discover -s tests`;
подготовка тренера проверяется отдельно в `.venv-training` через `tests_training`.

## Имя бота

На **Главной** введи имя в поле **Имя бота** и нажми **Применить имя**.
Можно также нажать Enter. Имя обращения и ник на сервере сохраняются вместе.
Если бот работает, он перезапустится и вернётся в свой текущий голосовой канал.
Повторное применение того же имени не вызывает перезапуск.

Для изменения ника в Discord нужно разрешение **Change Nickname / Изменять никнейм**.
Если разрешения нет, имя обращения всё равно изменится; на главной будет показан
фактический ник и подсказка о разрешении. Глобальное имя аккаунта задаётся отдельно
в Developer Portal и автоматически не меняется. Файл характера сохраняется без переписывания.
Для пользовательского имени бот откликается на выбранное обращение; имена из нескольких
слов и имена вне словаря Vosk проверяются полным распознаванием Whisper.

## Голос, модель и общение

В **Настройках бота** три вкладки:

- **Голос** — вариант голоса, темп речи и громкость.
- **Модель** — установленная разговорная модель и бюджет ресурсов компьютера.
  Загрузка других моделей находится в блоке **Добавить модель**, измерения —
  в блоке **Сравнение моделей и автоподбор — дополнительно**.
- **Общение** — когда отвечать, продолжать ли тему без имени и разрешать ли перебивание.

Кнопки **Сохранить** и **Сохранить и перезапустить** закреплены над вкладками.
Темп речи меняет произношение; задержка подготовки ответа зависит от модели,
распознавания, синтеза и текущей нагрузки. Больший бюджет ресурсов не гарантирует ускорение.

На главной выбор канала находится рядом с запуском бота. Графики нагрузки свёрнуты
в **Нагрузка компьютера и задержка**, повторная установка и папка данных —
в **Установка и обслуживание**. Эти разделы можно раскрыть в любой момент.

## Персона, история и постоянная память

«Сохранить характер» записывает характер в PERSONA.md. Он сохраняется после перезапуска и перечитывается при следующем ответе.

«Загрузить контекст» показывает свежую историю активного разговора на выбранном сервере. Отредактируйте её и нажмите «Применить»; программа сообщит, сколько реплик поместилось в лимит. История ограничена и очищается при перезапуске. Это не постоянная память и не замена персоны.

Для постоянного факта скажите боту по имени «запомни: …» или добавьте заметку в разделе «Память». Панельная заметка помечается как запись владельца, а не как слова другого участника. Сохранённые сведения переживают перезапуск. Заметки не меняют веса нейросети; LoRA остаётся отдельной экспериментальной функцией.


## Обновление приложения

Начиная с 1.0.4, приложение проверяет официальный GitHub Releases при запуске и раз в шесть часов. Проверку можно запустить вручную кнопкой «Проверить обновления» внизу слева. При доступной стабильной версии сверху появляется кнопка «Скачать обновление».

После нажатия установщик скачивается в фоне; бот работает до окончания загрузки. Приложение проверяет размер и SHA-256, останавливает бота, закрывается и запускает установку без дополнительных шагов. Затем панель открывается снова; если бот работал, он запускается и возвращается в прежний голосовой канал. Если бот был остановлен, самостоятельно запускаться он не будет.

Настройки, токен, модели, персона и постоянная память сохраняются в прежней папке данных. Данные Discord и содержимое разговоров серверу обновлений не отправляются. Проверяются только публичные сведения о выпуске. Загрузку можно отменить до начала установки. Предварительные версии не предлагаются.

При ошибке загрузки или несовпадении суммы установщик не запускается. При ошибке установки прежнее приложение открывается снова с сообщением; журнал находится в `logs/app-update-install.log`, результат — в `reports/app-update-result.json`. Для версий до 1.0.4 нужно один раз установить новый EXE поверх старого.
