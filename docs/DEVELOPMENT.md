# Разработка

Пользователю достаточно [установщика EXE](https://github.com/Roland525/sobesednik/releases/latest). Этот раздел — для изменения исходного кода.

Все исходники и средства разработки собраны в [`app/`](../app/). Команды ниже выполняйте из этой папки: `cd app`.

## Структура

- `bot/` — Discord, голос, модели и память.
- `desktop/` — приложение управления.
- `tools/` и `packaging/` — установка зависимостей и сборка EXE.
- `tests/`, `tests_desktop/`, `tests_training/` — проверки поведения и безопасности.
- `../.github/workflows/` — автоматические проверки изменений на GitHub.

Тесты и CI нужны, чтобы новые изменения не ломали команды, остановку речи, память и защиту токена. Запускать их для использования приложения не требуется.

## Локальный запуск

Откройте папку `app`, установите Python 3.11/3.12 и запустите `setup.bat`. Подробнее — [запуск из исходников](GUIDE.md#установка-одним-exe). Для запуска и остановки используются `start.bat` и `stop.bat`.

Проверки backend: `python -m unittest discover -s tests`.
Проверки интерфейса: `python -m unittest discover -s tests_desktop` в окружении с `requirements-desktop.txt`.
Обучение использует отдельное окружение; см. [LOCAL_LEARNING.md](LOCAL_LEARNING.md).

## Обязательное правило завершения desktop-приложения

Последовательность **«Остановить» → закрыть окно** должна завершать все процессы,
созданные этим экземпляром Собеседника: голосовой процесс, supervisor, собственную
Ollama и её model runners. Независимые процессы и серверы других проектов не завершаются.
Не используйте глобальное убийство процессов по имени, порту или наличию Python.

Собственные деревья запускаются только через OwnedProcess/Windows Job Object с
завершением при смерти владельца. Bootstrap получает команду после присвоения Job,
чтобы потомки не успели появиться вне дерева владения. Ошибки и отмена запуска должны
освобождать созданные серверы и журналы. Просмотр списка моделей не поднимает сервер;
временные загрузки и проверки освобождают свой сервер, если бот не работает.

Регрессии проверяют `tests/test_runtime_shutdown.py`, `tests/test_process_shutdown_integration.py`,
`tests/test_offline_model_inventory.py` и тест кнопки остановки в `tests_desktop/test_window.py`.
Проверки процессов используют только CPU-имитаторы на случайных свободных портах.

## Сборка

Установите `requirements-desktop.txt` в отдельное окружение и Inno Setup. Выполните `python tools/build_desktop.py --iscc ПУТЬ_К_ISCC.exe`.

Публикуйте только файлы из явного списка `tools/build_release.py`. Не добавляйте токены, конфигурацию пользователя, память, учебный корпус, логи и веса. `RELEASE_MANIFEST.json` содержит контрольные суммы исходников для сборки.
