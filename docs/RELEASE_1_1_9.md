# Собеседник 1.1.9

- Автопамять сразу сохраняет поддерживаемые законченные сведения: привычки, предпочтения, происхождение, оборудование и постоянные договорённости. Такие записи больше не ждут паузы в разговоре и фонового отбора моделью.
- Оценочные мнения о конкретном предмете сохраняются с автором и типом «Мнение». При воспоминании бот получает указание передавать их как слова участника. Изменение мнения по тому же предмету сохраняет историю предыдущей записи.
- В разделе памяти виден статус автоматического запоминания. Таблица различает сведения и мнения, в том числе для распознаваемых старых автозаписей. Исправлена ошибка отображения записей без служебного поля слота.
- В новых профилях автопамять, сбор примеров и автоматическое дообучение в простое включены по умолчанию. Явное отключение в существующих настройках сохраняется; отключённый сбор примеров не включает обучение после обновления.
- Дообучение весов остаётся экспериментальным: оно требует отдельно подготовленного тренера, совместимой модели, достаточных данных и простоя. Этот выпуск не загружает тяжёлое окружение тренера самостоятельно и не подменяет выбранную модель.
- Распознанные мнения исключены из автоматических пар для обучения: они остаются в памяти с авторством. Секреты, неясные обрывки, вопросы и команды менять правила по-прежнему не становятся автоматическими воспоминаниями.

Обновите приложение, полностью закройте его и откройте снова для извлечения нового backend. Если бот работает, сначала остановите его. После запуска проверьте **Память → Что запоминать автоматически**: ранее выключенные параметры сами не включатся.

Распознавание речи и поддерживаемые русские формулировки ограничивают полноту автоматического отбора. Для остальных сведений остаётся команда «запомни». Проверки подтверждают сохранение и поиск записей, а не универсальное понимание любых разговоров.
