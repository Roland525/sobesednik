# Собеседник 1.1.11

- **«Остановить» завершает и бота, и запущенное приложением дерево Ollama.** Собственный сервер моделей больше не остаётся до закрытия окна, даже если голосовой процесс уже завершился.
- Отмена и ошибка запуска закрывают собственный сервер и его журналы. При закрытии приложения освобождение сервера выполняется и при ошибке завершения голосового процесса.
- Открытие приложения и обновление списка моделей не запускают Ollama. При выключенном сервере список читается из полных локальных манифестов; незавершённые и повреждённые загрузки не считаются установленными.
- Загрузка моделей, установка, проверка качества и автоподбор используют сервер временно. Если бот не работает, запущенный приложением сервер закрывается по завершении, отмене или ошибке операции.
- Уже работающая независимая Ollama не становится собственностью приложения и не завершается им. Чужие проекты и порты не затрагиваются.

Проверены настоящие тестовые деревья процессов Windows: остановка освобождает их порты; принудительное завершение владельца закрывает дочерний сервер через Windows Job Object; отдельный сервер остаётся работать. В Qt проверена последовательность **«Остановить» → закрыть окно**. Нейросеть и Discord для этих проверок не запускались.

После обновления полностью закройте прежнюю версию и откройте новую. Настройки, модели, память и сохранённый характер остаются на месте.
